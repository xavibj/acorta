# 004 — API REST y redirección

El paquete `server` expone `Handler(svc, baseURL, static)`: la redirección de las URL cortas, la API JSON bajo `/api/` y la interfaz web embebida. Todo en el mismo origen, sin CORS. Sin autenticación en la v1 (ver spec 000).

## Rutas

| Método y ruta | Qué hace |
|---|---|
| `GET /{código}` | Redirige a la URL de destino y cuenta la visita |
| `HEAD /{código}` | Lo mismo, sin contar la visita |
| `GET /api/healthz` | Comprobación de vida |
| `POST /api/links` | Crea un enlace |
| `GET /api/links` | Lista los enlaces |
| `DELETE /api/links/{código}` | Borra un enlace |
| `GET /` | La interfaz web (`index.html` del frontend compilado) |
| `GET /assets/…` y rutas de un segmento con punto (`/favicon.svg`) | Ficheros estáticos embebidos |

Un código nunca contiene un punto ni una barra, así que las URL cortas no chocan con los ficheros estáticos ni con `api` y `assets`, que son palabras reservadas (spec 002).

## El enlace en JSON

```json
{
  "code": "k3x9ab",
  "url": "https://example.com/una/ruta/larga",
  "short_url": "http://localhost:8080/k3x9ab",
  "visits": 0,
  "created_at": "2026-10-01T12:00:00Z",
  "expires_at": null,
  "expired": false
}
```

`short_url` es la URL base del servidor (sin barra final) + `/` + el código. `expired` se calcula en el momento de responder.

## Redirección

- **RED-01** — Dado un código que existe y no ha caducado, `GET /{código}` responde `302 Found` con `Location` igual a la URL de destino y `Cache-Control: no-store`, y suma una visita. Es 302 y no 301 a propósito: un 301 lo guarda el navegador y las visitas siguientes no llegarían al servidor.
- **RED-02** — Dado un código que no existe, responde `404` con `Content-Type: text/plain; charset=utf-8` y el texto `enlace no encontrado`.
- **RED-03** — Dado un código caducado, responde `410 Gone`, `text/plain`, con el texto `enlace caducado`. No suma visita.
- **RED-04** — `HEAD /{código}` responde con el mismo estado y las mismas cabeceras que `GET`, sin cuerpo y sin sumar visita.
- **RED-05** — Otro método sobre `/{código}` (`POST`, `DELETE`…) responde `405` con la cabecera `Allow: GET, HEAD`.
- **RED-06** — Una ruta de más de un segmento que no sea de la API ni un estático (`/a/b`) responde `404` `text/plain`.

## API

Toda respuesta bajo `/api/` lleva `Content-Type: application/json` y termina en salto de línea. Los errores tienen siempre la forma `{"errors": ["…", "…"]}`.

- **API-01** — `GET /api/healthz` responde `200` `{"status":"ok"}`.
- **API-02** — `POST /api/links` con `{"url":"https://example.com"}` responde `201` con el enlace en JSON: código generado, `visits` 0, `expires_at` `null`, `expired` `false`.
- **API-03** — `POST /api/links` con `alias` y `expires_at` válidos responde `201` con ese código y esa caducidad (en UTC).
- **API-04** — Si la validación falla, responde `400` con **todos** los mensajes de la spec 002, sin cambiarlos y en su orden. Ejemplo: `{"url":"ftp://x","alias":"A"}` → `{"errors":["url: debe empezar por http:// o https://","alias: debe tener entre 3 y 32 caracteres"]}`.
- **API-05** — Si el alias ya está en uso, responde `409` con `{"errors":["alias: \"promo\" ya está en uso"]}`.
- **API-06** — Si el cuerpo no es un objeto JSON válido, tiene campos desconocidos, un campo de tipo incorrecto o datos después del objeto, responde `400` con `{"errors":["el cuerpo debe ser un objeto JSON con url, alias y expires_at"]}`. El cuerpo se limita a 64 KiB; si lo supera, la misma respuesta.
- **API-07** — Si no se puede generar un código libre (COD-02), responde `503` con `{"errors":["no se ha podido generar un código libre; inténtalo de nuevo"]}`.
- **API-08** — `GET /api/links` responde `200` con un array de enlaces en el orden de LIS-01; sin enlaces, `[]`.
- **API-09** — `DELETE /api/links/{código}` de un enlace que existe responde `204` sin cuerpo; después, `GET /{código}` da `404`.
- **API-10** — `DELETE /api/links/{código}` de uno que no existe responde `404` con `{"errors":["enlace no encontrado"]}`.
- **API-11** — Una ruta desconocida bajo `/api/` responde `404` con `{"errors":["ruta no encontrada"]}`.
- **API-12** — Un método no admitido en una ruta de la API responde `405` con la cabecera `Allow` y `{"errors":["método no permitido"]}`.
- **API-13** — Un fallo interno (el almacén no responde) da `500` con `{"errors":["error interno"]}`. El detalle va al log del servidor, no a la respuesta.

## Estáticos

El frontend compilado no está en Git (spec 001). El servidor recibe un sistema de ficheros (`fs.FS`) y sirve lo que haya en su carpeta `dist/`; el binario le pasa el embebido y los tests, uno en memoria. Así los tests no dependen de que alguien haya compilado el frontend.

- **EST-01** — Dado un sistema de ficheros con `dist/index.html`, `GET /` responde `200` `text/html` con su contenido.
- **EST-02** — Cada fichero de `dist/` se sirve en su ruta sin el prefijo (`dist/assets/app-3f9a.js` en `/assets/app-3f9a.js`, `dist/favicon.svg` en `/favicon.svg`) con `200` y su tipo de contenido correcto.
- **EST-03** — Un fichero estático que no existe (`/assets/nada.js`, `/nada.txt`) responde `404` `text/plain`.
- **EST-04** — Dado un sistema de ficheros sin `dist/index.html` (frontend sin compilar), `GET /` responde `200` `text/html` con la página de aviso `sin-compilar.html`, que dice `Frontend sin compilar` y cómo arreglarlo (`make frontend`). La API y las redirecciones funcionan igual.
- **EST-05** — El sistema de ficheros embebido en el binario (`server.Static()`) contiene siempre `sin-compilar.html`, que sí está en Git: por eso `go build` funciona en un clon recién hecho.

## Contrato del paquete

```go
package server

// Service es lo que el servidor necesita de shortener.Service.
type Service interface {
    Create(ctx context.Context, in link.Input) (link.Link, error)
    Resolve(ctx context.Context, code string, countVisit bool) (string, error)
    List(ctx context.Context) ([]link.Link, error)
    Delete(ctx context.Context, code string) error
    Now() time.Time
}

// Handler devuelve el servidor completo. baseURL se usa para short_url;
// static es el sistema de ficheros con sin-compilar.html y, si existe, dist/.
func Handler(svc Service, baseURL string, static fs.FS) http.Handler

// Static devuelve los ficheros embebidos en el binario (server/static/).
func Static() fs.FS
```
