# acorta

Acortador de URLs en un único binario Go, con API REST, CLI e interfaz web en Vue.

Es el proyecto conductor del tutorial [iadev.xavi.net](https://iadev.xavi.net): se construye con especificaciones (SDD), tests primero (TDD) y un agente de código, y el tutorial enseña cómo, con fragmentos reales de este repositorio.

**Estado: especificado, sin implementar.** El contrato está en [`specs/`](specs/000-especificacion.md); las reglas para los agentes, en [`AGENTS.md`](AGENTS.md); y las decisiones que llevaron hasta aquí, en [`bitacora/`](bitacora/).
